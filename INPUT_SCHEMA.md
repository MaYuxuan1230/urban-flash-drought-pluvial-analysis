# Input schema

The analysis starts from three city/event-level tables generated by the study's
data-processing workflow. Column names are case-sensitive. Additional columns
are permitted.

## `city_events`

One row per flash-drought event.

| Field | Description |
|---|---|
| `event_id` | Unique event identifier |
| `city_id` | Unique city identifier |
| `event_type` | `FD_only` or `FD_P` |
| `fd_onset` | Flash-drought onset date |
| `sm_min_pct_weighted` | Area-weighted minimum soil-moisture percentile |
| `decline_rate_weighted` | Area-weighted onset decline rate |
| `fd_duration_days_weighted` | Area-weighted event duration in days |
| `vpd_mean_drought` | Mean vapour-pressure deficit during drought |

Optional event-intensity fields used by script 01 are checked at run time.

## `city_year`

One row per city and year, including zero-event years.

| Field | Description |
|---|---|
| `city_id` | Unique city identifier |
| `year` | Calendar year |
| `city_name` | City name |
| `longterm_aridity_index` | Long-term precipitation/PET ratio |
| `annual_aridity_index` | Annual precipitation/PET ratio |
| `vegetation_fraction` | Urban vegetation fraction (0–1) |
| `built_up_fraction` | Built-up fraction (0–1) |
| `annual_vpd_mean` | Annual mean vapour-pressure deficit |
| `dominant_climate_code` | Dominant climate-class code |

For aridity and built-up fraction, the scripts accept the documented aliases
shown in their validation messages.

## `event_response_long`

Parquet table with one row per event, response variable, alignment and lag.

| Field | Description |
|---|---|
| `event_id`, `city_id`, `event_type` | Event identifiers |
| `alignment` | `fd` or `transition` |
| `lag` | Relative 8-day window |
| `variable` | Response-variable name |
| `eightday_start` | Start date of the 8-day window |
| `detrended_standardized_anomaly` | Primary event response in standardized units |
| `standardized_anomaly` | Fallback standardized response |
| `detrended_anomaly` | Physical-unit detrended response where required |

The manuscript analyses use, among others, `evi_vegetation`, `gpp_primary`,
`thermal_excess_day_all` and `vpd_mean`.

## Derived tables

Script 02 creates `event_response_metrics.parquet`. Scripts 03–05 read this
derived output directly; no unpublished Figure-specific input table is needed.
